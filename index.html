Period Templates

A period template is a daily structure (period numbers, labels, timings, breaks). Add a template, click it to manage its periods, then map it to days below — e.g. one template for Mon–Fri and a different one for Saturday. You can also add extra templates for special days (half days, exam schedules, events).

Day → Template

Which period template applies to each day of the week.

Special Days

One-off calendar dates use their own period template, separate from the normal weekly timetable (e.g. Sports Day, an exam day, or a half day).

Class Subject Period Targets

Select a class only — never a section. Each target is applied to all sections of that class; the Builder shows each section's scheduled total separately.

Teacher Class & Subject Details

Select a class, then tick the subjects taught there. Sections are optional and multi-selectable (ctrl/cmd-click, or tap to multi-select on mobile) — leave none selected to apply to every section of that class, or pick one or more sections to target just those. This guides the timetable picker and auto-substitution ranking.

Bulk Import Timetable Setup

Bulk upload classes, subjects, Class Subject Period Targets, or Teacher Class & Subject Details from CSV. For targets and teacher details, use the class name only; the upload applies each row to every section in that class.

Weekly Timetable Builder

Pick a class, then click any cell to assign or change its subject & teacher for that day/period. A teacher already booked elsewhere at that day/period is automatically excluded from the picker.

Timetable Teacher List

This list uses your Staff records. Use View / Edit to see each teacher's timetable teaching details and allocate the classes and subjects they teach.
